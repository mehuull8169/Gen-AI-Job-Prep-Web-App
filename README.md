# Gen-AI Job Prep Web App

A full-stack web application that helps users prepare for job interviews with AI-generated questions, practice sessions, and feedback.

## Features

- AI-powered mock interview practice
- Dynamic interview question generation
- Feedback and evaluation
- User registration and login
- Interview reports

## Tech Stack

- **Frontend:** React.js, Vite, SCSS
- **Backend:** Node.js, Express.js
- **AI:** Generative AI API integration
- **Database:** Update with the database used in this project

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mehuull8169/Gen-AI-Job-Prep-Web-App.git
cd Gen-AI-Job-Prep-Web-App
```

### 2. Backend Setup

```bash
cd Backend
npm install
```

Configure your environment variables in a local `.env` file. Never commit API keys or secrets.

Run the backend using the start command defined in `Backend/package.json`.

### 3. Frontend Setup

Open another terminal:

```bash
cd Frontend
npm install
npm run dev
```

Open the local URL provided by Vite.
